# PoseMate-AI
PoseMate is an AI-powered yoga pose detection and feedback system that leverages MediaPipe, Computer Vision, and Deep Learning to provide real-time posture analysis and personalized guidance for safe and effective home-based yoga practice.

Features:
-> MediaPipe-Enhanced Training Images – Training images are enhanced using MediaPipe skeletal landmarks, allowing the model to focus on body posture rather than background noise, resulting in improved learning and higher accuracy.
-> Landmark Feature Extraction – Extracts 33 body landmarks and their spatial coordinates from each frame, providing robust skeletal features for accurate yoga pose recognition.
-> Joint Angle Calculation – Calculates angles between key body joints to precisely evaluate posture alignment and identify deviations from the ideal yoga pose.
-> Improved Accuracy & Performance – Combines skeletal overlays, landmark-based features, and joint angle analysis to enhance pose classification accuracy, reduce false predictions, and deliver reliable real-time feedback.
